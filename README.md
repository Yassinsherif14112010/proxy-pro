# Proxy Pro

بروكسي بيشتغل بطريقتين على **نفس الـ IP:Port**:

1. **واجهة ويب** (Scramjet + Wisp + libcurl): `http://IP:PORT/` — تبويبات، يوتيوب، ألعاب، بحث.
2. **بروكسي شبكة (HTTP + CONNECT)**: اكتب `IP` و`PORT` في إعدادات البروكسي بالجهاز. من غير flags، وبيشتغل على أي جهاز (آيفون/أندرويد/ويندوز). **ده الأسرع والأضمن ليوتيوب وPoki.**

## التشغيل على Termux (الأندرويد)
```bash
pkg update && pkg install nodejs -y
termux-wake-lock
cd ~ && unzip proxy-pro.zip && cd proxy-pro   # أو انسخ المجلد
npm install
WORKERS=1 ./start.sh
```
بعدين اعرف IP الموبايل (`ifconfig` أو من إعدادات الواي فاي) واستخدمه من باقي الأجهزة على نفس الشبكة.

## التشغيل على أي VPS / كمبيوتر
```bash
npm install
cp .env.example .env   # عدّل القيم
./start.sh
```
للتشغيل الدائم: `npm i -g pm2 && pm2 start start.sh --name proxy`.

## إعداد بروكسي الشبكة على الجهاز
- **أندرويد:** الواي فاي ← تعديل الشبكة ← خيارات متقدمة ← Proxy: يدوي ← Host: `IP` / Port: `PORT`.
- **آيفون:** الواي فاي ← (i) ← Configure Proxy ← Manual.
- **ويندوز:** Settings ← Network ← Proxy ← Manual proxy setup.
لو فعّلت `PROXY_USER/PROXY_PASS` المتصفح هيسأل عن اليوزر والباسورد.

## واجهة الويب على `http://IP:PORT`
المتصفح بيمنع الـ Service Worker على http العادي، فلازم مرة واحدة على كل جهاز:
`chrome://flags/#unsafely-treat-insecure-origin-as-secure` ← فعّلها ← اكتب `http://IP:PORT` ← Relaunch.
(الآيفون/سفاري مش بيدعم الحيلة دي، استخدم بروكسي الشبكة بدلها.)

## التحمل والأمان (مدمج)
- cluster على عدة عمليات، وإعادة تشغيل تلقائية لأي worker يقع.
- حد اتصالات CONNECT لكل IP (`MAX_TUNNELS_PER_IP`) وحد إجمالي، وRate limit للطلبات، ومهلة للاتصالات الخاملة.
- حظر الوصول لعناوين الشبكة الداخلية (SSRF) وبورتات السبام (25/465/587).
- كاش DNS، وضغط Brotli/Gzip للملفات الثابتة مع كاش في الذاكرة.
- `/healthz` و`/stats` للمراقبة.
- عدّادات الحدود لكل worker، فالحد الفعلي = القيمة × عدد الـ workers.

## تنبيهات صريحة
- **التحقق "أنا لست روبوت" من جوجل مش هيختفي 100%**: السبب IP واحد بيطلب منه ناس كتير. استخدم DuckDuckGo/Brave (الافتراضي هنا)، وبروكسي الشبكة بيقلل المشكلة. يوتيوب ممكن يطلب تسجيل دخول لو الـ IP datacenter.
- السرعة = سرعة نت الجهاز اللي شغّال عليه. فيديو يوتيوب بياخد 2-5 ميجابت للمستخدم.
- كتير من الاستضافات (منها botkeep.cloud) **بتمنع البروكسي في شروطها**، فاقرأ شروط أي استضافة قبل الرفع.

## الرفع على استضافات Pterodactyl (XSystems / Wispbyte وغيرها)
> اقرأ شروط الاستضافة وتأكد إنها بتسمح بالبروكسي قبل الرفع، وإن لوحتها بتديك IP:Port عام. جرّب بحساب مش مهم الأول.

1. ارفع محتوى المجلد كله (النسخة `proxy-pro-host.zip` فيها `node_modules` جاهزة، فمش محتاج `npm install`) ثم فك الضغط من File Manager.
2. اتأكد إن ملف التشغيل (Startup / JS file) هو `index.js` والنوع Node.js (18 أو أحدث، والأفضل 20+).
   لو اللوحة بتطلب أمر كامل: `node index.js`
3. البورت بيتاخد تلقائياً من `SERVER_PORT` اللي اللوحة بتديهوله. مش لازم تعدّل حاجة.
4. شغّل السيرفر. هتلاقي في الكونسول: `Web UI: http://IP:PORT/`. استخدم نفس `IP` و`PORT` كبروكسي في الجهاز.
5. لتغيير الإعدادات (يوزر/باسورد مثلاً) أنشئ ملف `.env` جنب `package.json` (شوف `.env.example`).
6. لو لقيت إن لوحة الاستضافة بتعمل `npm install` تلقائياً وفشل، احذف مجلد `node_modules` وخلّيها تثبّت بنفسها، أو العكس.
- الرام المحدودة (≤1GB) بتخلي السيرفر يشتغل بعملية واحدة وحدود أقل تلقائياً.
- `GET /stats` بيوريك الذاكرة المستهلكة، و`/healthz` للفحص.
